Подключение кнопок заказов Telegram

1. В Google Apps Script проекта замените Code.gs файлом из этого архива.
2. Сохраните проект и разверните новую версию существующего веб-приложения. Оставьте доступ веб-приложения таким, как требуется сайту и Telegram webhook.
3. В редакторе Apps Script выберите installTelegramBookingWebhook и нажмите «Выполнить». При первом запуске предоставьте запрошенные разрешения. Функция установит webhook для callback_query и создаст секрет в Script Properties.
4. Убедитесь, что в Script Properties уже заданы TELEGRAM_BOT_TOKEN, ADMIN_TELEGRAM_USER_ID и MASTER_TELEGRAM_USER_ID.

Новые заявки занимают слот со статусом «Ожидает подтверждения». Подтверждение переводит запись в «Активна» и показывает её в админ-панели. Отмена переводит в «Отменена» и освобождает слот.
