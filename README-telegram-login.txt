Вход в админ-панель через Telegram

Google-вход полностью удалён. Администратор и мастер входят через Telegram Login
Widget. Сервер проверяет подпись данных Telegram и разрешает вход только ID из
Script Properties: ADMIN_TELEGRAM_USER_ID и MASTER_TELEGRAM_USER_ID.
Используется существующий TELEGRAM_BOT_TOKEN. Имя бота сайт получает с сервера.

Первоначальная настройка:
1. В BotFather отправьте /setdomain, выберите бота и укажите домен, на котором
   открывается админ-панель. Это домен сайта, не script.google.com.
2. Скопируйте Code.gs в Apps Script и обновите ТЕКУЩЕЕ развёртывание:
   Управление развёртываниями → карандаш → Новая версия → Развернуть.
   Сохраните существующий URL /exec. Webhook переустанавливать не нужно.
3. Опубликуйте admin/admin.html и admin/service-worker.js на хостинге сайта.
4. Откройте админку, нажмите кнопку Telegram и подтвердите вход.

Сессия действует не более шести часов и хранится только в памяти страницы.
После перезагрузки страницы нужен повторный вход. Если Apps Script раньше
очистит кэш сессии, понадобится войти снова. «Выйти» удаляет серверную сессию.
Изменение разрешённых Telegram ID закрывает доступ прежнему пользователю
при следующем административном запросе.

Мастер может входить независимо от настройки автоуведомлений Telegram.
Выключенные уведомления мастеру остаются выключенными.

Проверка:
- аккаунты администратора и мастера должны входить и получать записи;
- посторонний Telegram-аккаунт должен получить отказ;
- после выхода административные операции требуют нового входа;
- сообщение Bot domain invalid означает, что в BotFather не привязан домен
  именно той страницы, на которой открыта админка.

Документация виджета: https://core.telegram.org/widgets/login-legacy
